# 새결 — 건축의 다음을 발견하다

건축 신제품과 소재를 분야별로 소개하는 한국어 정적 사이트입니다. `index.html`을 브라우저에서 열면 실행됩니다.

## GitHub Pages
1. GitHub에서 새 공개 저장소를 만듭니다.
2. `main` 브랜치를 저장소에 push합니다.
3. **Settings → Pages → Deploy from a branch → main → /(root)** 를 선택합니다.

제품명과 설명은 시안용 예시 콘텐츠이며, 실제 제품 정보와 출처로 교체하세요. 사진은 Unsplash 원격 이미지입니다. GitHub Pages에 게시하기 전에 이미지 사용 조건을 확인해주세요.
